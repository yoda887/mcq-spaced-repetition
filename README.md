# MCQ Spaced Repetition

Плагин Obsidian для интервального повторения карточек: тесты с вариантами ответа,
карточки с вводом ответа, cloze-пропуски и обычные вопрос/ответ.

> Исходники восстановлены из собранного `main.js` версии 1.1.0 (включая правки
> экрана проверки). Сборка из этих исходников даёт функционально тот же `main.js`.

## Синтаксис карточек

| Синтаксис | Тип |
|---|---|
| `Вопрос :: Ответ` | обычная карточка |
| `Вопрос ::: Ответ` | двусторонняя (создаёт прямую и обратную) |
| Абзац: вопрос, строка `?`, ответ | многострочная |
| Абзац: вопрос, строка `??`, ответ | многострочная двусторонняя |
| `Текст {{пропуск}}` или `Текст ==пропуск==` | cloze, ответ показывается по кнопке |
| `Текст {{type:ответ}}` | cloze с вводом ответа |
| `:::block` … `:::` с `{{type:...}}` внутри | блок с вводом ответов |
| `:::test` … `:::` с вариантами `- [ ]` / `- [x]` | тест с выбором ответа; если отмечено несколько `[x]` — нужно выбрать все правильные |

Альтернативные правильные ответы разделяются словами `or` / `или`:
`{{type:colour or color}}`.

Расписание хранится в заметке комментарием после карточки:

```
<!--SR:2026-10-01,7,2.45,f:12.5:4.2:2:3:1:2026-09-24-->
       дата      инт ease  FSRS: стабильность:сложность:состояние:повторы:провалы:последний повтор
```

Часть `f:...` появляется после первой оценки по FSRS. Старые комментарии без неё
читаются как раньше.

## Алгоритм интервалов

По умолчанию используется **FSRS** (библиотека [ts-fsrs](https://github.com/open-spaced-repetition/ts-fsrs)).
Он оценивает стабильность и сложность каждой карточки по истории ответов и назначает
повтор на день, когда вероятность вспомнить опустится до заданной (по умолчанию 90%).
Карточки, которые оценивались по SM-2, переносятся приблизительно: стабильность
принимается равной текущему интервалу, сложность вычисляется из ease.

В настройках можно вернуться к SM-2, изменить желаемую вероятность и максимальный интервал.

## Сессия повторения

- Карточка, отвеченная **Again**, возвращается в конце той же сессии и отмечается
  «повтор ошибки», пока на неё не будет дан верный ответ. Расписание в заметке
  записывается только при первом ответе.
- Карточки перемешиваются, карточки из одной заметки по возможности не идут подряд,
  из двусторонней карточки в сессию попадает только одна сторона.
- Варианты в тестах `:::test` перемешиваются. Неверный ответ в тесте засчитывается
  как Again: тест вернётся в конце сессии с заново перемешанными вариантами.
- Любое действие в сессии можно отменить: оценку, пропуск, откладывание.

Перемешивание карточек и вариантов отключается в настройках плагина.

| Клавиша | Действие |
|---|---|
| `1` `2` `3` `4` | Again / Hard / Good / Easy |
| `1`–`9` | в тестах — выбор варианта (номер показан перед вариантом) |
| `Enter` | проверить ответ, затем рекомендованная оценка |
| `Space` / `Enter` | показать ответ |
| `U` | отменить последнее действие |
| `S` | пропустить карточку (показать позже в этой сессии) |
| `B` | отложить карточку до завтра |

Буквенные клавиши работают и в русской раскладке (`Г`, `Ы`, `И`).

## Структура

```
src/
  main.ts             класс плагина: команды, кэш карточек, сессии, Focus Queue
  FlashcardParser.ts  разбор заметок в карточки и запись расписания в файл
  ReviewModal.ts      окно повторения
  AnswerCheck.ts      проверка введённых ответов: нормализация, опечатки, diff
  scheduler.ts        FSRS (ts-fsrs) и SM-2: расчёт следующего повтора
  queue.ts            порядок карточек в сессии: перемешивание, разнесение, парные карточки
  settings.ts         вкладка настроек
  SM2.ts              алгоритм SM-2
  FocusQueueView.ts   боковая панель: Focus Queue, колоды, навыки, статистика
  livePreview.ts      подсветка {{type:...}} и :::block/:::test в Live Preview
  readingView.ts      отображение пропусков и блоков в режиме чтения
  tags.ts             теги заметки (для колод и навыков)
  types.ts            общие типы
tests/                автотесты (vitest)
styles.css            стили
manifest.json         описание плагина для Obsidian
```

## Сборка

Нужен Node.js 18+.

```bash
npm install
npm run build      # проверка типов, тесты и сборка main.js
npm test           # только тесты
npm run dev        # сборка с отслеживанием изменений
```

Для установки скопируйте `main.js`, `styles.css` и `manifest.json` в
`<хранилище>/.obsidian/plugins/mcq-spaced-repetition/` и перезагрузите плагин.

Удобнее разрабатывать прямо в хранилище: склонируйте репозиторий в папку
`.obsidian/plugins/mcq-spaced-repetition/`, запустите `npm run dev` и
перезагружайте плагин после изменений (например, плагином Hot-Reload).

## Выпуск версии

```bash
npm version patch   # обновит package.json, manifest.json и versions.json
```
